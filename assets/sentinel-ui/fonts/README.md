# IBM Plex interface fonts

IBM Plex Sans Regular and IBM Plex Mono Regular are vendored from IBM's official
`IBM/plex` repository (`packages/plex-sans/fonts/complete/woff2` and
`packages/plex-mono/fonts/complete/woff2`). Retrieved 2026-09-21.

These fonts are served locally. No runtime font request leaves the local host.
